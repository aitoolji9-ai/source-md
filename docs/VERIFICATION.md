## 발견해 수정한 문제

- 이 컴퓨터의 절대 경로를 쓰던 스킬 실행기: 체크아웃 자동 탐색 및 명시적 설치 바인딩으로 변경했다. 상대 입력·출력의 기준 작업 폴더를 보존한다.
- 다운로드 경로에서 결과 묶음 밖으로 향하는 심볼릭 링크: 404로 거부한다.
- Pillow 12.3.0: pip-audit에서 알려진 항목 39개를 보고해 13.0.0으로 갱신하고 실제 이미지/OCR 회귀를 다시 수행했다. [공식 수정 내역](https://pillow.readthedocs.io/en/stable/releasenotes/13.0.0.html)
- 손상된 manifest: KeyError traceback 대신 구조화된 검증 실패를 반환한다. 누락·잘못된 자료형·범위·외부 manifest를 거부하고 CLI는 종료 2로 보고한다. schema_version은 불리언/실수 대신 정수 1만 허용한다. DOM 스냅샷과 OCR 교정에도 같은 버전 규칙을 적용했다.
- 변하는 공개 Python 문서: 해시 불일치를 실패로 확인한 뒤 원래 검증 입력의 스냅샷·출처·라이선스를 포함했다. 기대값을 현재 문서에 맞춰 자동 완화하지 않았다.
- 공유 내보내기: 개인 출력·비밀 설정·로컬 스킬 바인딩·등록되지 않은 바이너리 표본을 복사하지 않는 실제 시험을 추가했다. 포함 HWP는 공개 출처·등록 SHA-256을 대조한다.

## 결과의 범위

`doctor`는 의존성 존재 점검이며 실제 OCR·변환 성공을 인증하지 않는다. 원본 SHA-256·저장 파일 해시·MD 단위 범위는 저장 무결성의 근거다. OCR/구조 후보의 일치와 모든 문서의 시각·의미 정확도는 별개다. 원본 대조 화면과 이전 인식·교정 이력을 보존하며 자동 결과를 모두 정확하다고 승격하지 않는다.

무한 목록의 완결, 모든 사이트/탭 조합, 임의 HWP 변형, 사진·손글씨·복잡한 배치 전체의 정확도는 이 검사로 인증하지 않는다. 상한·미검사·거부·후보 불일치는 보고서에 남긴다. 이 Mac에서 기본 표의 후보 불일치 검토 표시도 그대로 유지했다.

GitHub Actions에는 Linux/macOS 회귀·wheel 설치, 별도 Chromium 통합, 의존성 검사를 구성했다. **원격 CI 실행과 다른 OS의 실제 통과는 로컬 결과에 합산하지 않는다.** 브라우저 UI 시험 후 manifest 검증부가 수정됐으며, 수집·화면 코드가 동일한 바이트임을 대조하고 최종 검증부는 CLI/API·독립 재시험으로 확인했다. 최종 배포 파일의 SHA-256은 배포본 옆 `SHA256SUMS`로 제공한다.
